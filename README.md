# GH-300 Practice Exam — GitHub Copilot Certification

Interactive multiple-choice practice exam for the **GH-300 GitHub Copilot** certification.

## Features

- **50 multiple-choice questions** across all 7 exam domains
- **Study Mode** — flip through cards one at a time with instant feedback and explanations
- **Exam Mode** — timed simulation with 10, 25, or 50 randomized questions
- **Results Dashboard** — score breakdown by domain, pass/fail indicator, full review
- Filter by domain, shuffle, keyboard navigation

## Exam Domains Covered

| Domain | Questions |
|--------|-----------|
| Responsible AI | 6 |
| Plans & Features | 7 |
| Data Handling | 7 |
| Prompt Engineering | 7 |
| Copilot Chat | 11 |
| Testing | 5 |
| Privacy & Exclusions | 7 |

## Getting Started

```bash
npm install
npm run dev
```

## Deploy to Vercel

```bash
npm install -g vercel
vercel
```

Or connect your GitHub repo to [vercel.com](https://vercel.com) for automatic deployments.
